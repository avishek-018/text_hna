# Hidden Neuron Activation Analysis on Labeled Text Data


In this work we used concept induction process to understand the decision making process of a Deep Learning model while it classifies a text. We used the AG NEWS Classification Dataset and LSTM for this task. We identified 19 neurons that basically helped the model to choose a certain class for a news example.
